# Privacy, Consent, and Records Policy

The submission workflow now records separate, versioned consent entries for:

- digital archiving of the manuscript;
- the institutional privacy notice; and
- copyright acknowledgement.

Each consent is linked to the submitting user and manuscript, with timestamp and request IP address. Consent records are not stored in browser local storage and are included in the PostgreSQL audit trail.

Before institutional use, Mabini Colleges must approve the final consent wording, retention period, access classification for confidential research, correction/deletion procedure, and designated data-protection contact. These operational decisions are required for compliance with RA 10173, RA 8293, and institutional research policy; the software cannot determine them automatically.
