# E-Data Banking System User Manual

## Student researcher

1. Log in using the assigned account and complete MFA when enabled.
2. Open Submission and complete the title, authors, category, school year, abstract, keywords, and PDF fields.
3. Read and accept the digital archiving, privacy, and copyright acknowledgement.
4. Submit the manuscript. The system shows `queued` while OCR, indexing, and similarity analysis run in the background.
5. Monitor status and notifications in Repository.

## Faculty reviewer

1. Open Repository and filter manuscripts assigned for review.
2. Review the PDF, similarity report, extracted text, and workflow history.
3. Approve, reject, or request a revision with reviewer notes.

## Administrator

1. Manage active users and reviewer assignments from Security.
2. Review audit logs, workflow events, and analytics.
3. Run database migration before schema changes and run encrypted backups according to the approved records-retention schedule.
