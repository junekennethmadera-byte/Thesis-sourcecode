# Usability and Acceptance Evaluation Plan

Evidence to retain: anonymized participant role, task results, timestamps, error counts, satisfaction scores, accessibility findings, consent to participate, and the signed evaluator summary. Do not collect thesis content or unnecessary personal information during usability testing.

Evaluate student researchers, faculty reviewers, and administrators using the same representative tasks:

- sign in and recover an account;
- submit a PDF with consent;
- locate a manuscript using title, author, category, and natural-language search;
- review OCR, similarity, citation, and workflow results;
- approve/request revision and view audit history;
- manage users and reviewer assignments.

Record task completion rate, time-on-task, errors, accessibility observations, and a 1–5 satisfaction score. Test keyboard navigation, readable contrast, screen-reader labels, mobile layout, and current Chrome/Edge/Firefox versions. Acceptance should require no critical security/data-loss defect, at least 90% completion for core tasks, and documented remediation for every failed task.
